# Contributing

Thank you for your interest in contributing.

## Ways to contribute

- improve documentation
- propose fixes
- create examples or integrations
- test workflows and APIs
- open clear pull requests with explanation

## Contribution rules

1. Keep changes focused and well explained.
2. Use clear commit messages.
3. Include tests when relevant.
4. Document behavioral changes.
5. Respect the project’s licenses and existing coding conventions.

## Pull requests

Before opening a pull request:

- create a feature branch
- keep the scope narrow
- describe the problem and the solution
- link related issues if applicable

## Repository contributor status

This repository is public and maintained by the GitHub user `azami-id`.

GitHub permissions determine whether someone is considered a contributor or maintainer. Public repo visibility alone does not create a formal code contributor relationship with an external project. If you are working directly on an Anthropic repository, contribution status is usually tied to:

- being a collaborator on the repository
- opening a pull request to that repository
- having the repository ownership or maintainer access

## Contact

Use the repository issue tracker for questions and collaboration proposals.
